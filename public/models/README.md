# Textured 3D model location

Place **pip-boy-fallout-3-web.glb** in this directory.

The file is the web-optimized version of the user's Sketchfab download of [Pip-Boy Fallout 3 Concept](https://sketchfab.com/3d-models/pip-boy-fallout-3-concept-21bfe974c2564ebabcc974b39a2a1f00) by Julien Schoots. The GitHub text-file integration cannot transfer GLB binary contents directly; therefore the file must be added separately.

This README is not the 3D model. Until the binary file is present, the app uses the previous procedural 3D shell. See ../../ASSET_CREDITS.md for license and modifications.
